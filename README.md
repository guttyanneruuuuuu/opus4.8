# 🪐 Orbit Clash（オービットクラッシュ）

明るく爽やかなパステルカラーの世界で繰り広げる、新感覚のリアルタイム1対1対戦アクションゲーム。スマホブラウザでそのまま遊べます。

## 🎮 ゲームの特徴（既存ゲームにない独自要素）

- **重力リング・アリーナ**：円形ステージの内壁を駆け回る。重力は常に円の中心へ向かうので、ステージはぐるりとループ。横でも縦でもない新感覚のアクション。
- **エナジーオーブの奪い合い**：中央に浮かぶオーブを集めてエナジーをチャージ。満タンで強力な「ワープショット」を発射。
- **シンプル操作・深い読み合い**：移動 / ジャンプ / ダッシュ / ガード / チャージショット の5要素だけで、白熱する駆け引きが生まれる。

## 🌈 デザイン

暗いネオン系は一切なし。クリーム・コーラル・スカイブルー・ミントを基調にした、陽だまりのように温かく爽やかなパステルワールド。

## 🕹 遊び方

| 操作 | PC | スマホ |
|------|----|----|
| 移動 | ← → / A D | 左の方向パッド |
| ジャンプ | ↑ / W / Space | ジャンプボタン |
| ダッシュ | Shift | ダッシュボタン |
| ガード | ↓ / S | ガードボタン |
| ショット | J / Enter | ショットボタン |

## モード

- **AI対戦**：やさしい / ふつう / つよい の3段階
- **友達対戦**：ルームコードを共有してリアルタイムP2P対戦（WebRTC）
- **ローカル対戦**：1台で2人対戦

## 起動方法

```bash
# 任意の静的サーバーで配信
python3 -m http.server 8080
# → http://localhost:8080
```

依存パッケージなし・ビルド不要。`index.html` を開くだけで動きます。

## 技術構成

- Pure HTML5 Canvas + Vanilla JavaScript（ES Modules）
- 物理演算・描画・AI・ネットワークすべて自前実装
- WebRTC（PeerJS）による P2P 対戦
